# StudyPilot 🎓

**Tu copiloto académico.**

StudyPilot es un proyecto en desarrollo para ayudar a estudiantes universitarios a organizar sus tareas, planificar sus estudios y reducir la procrastinación.

## Objetivo

Ayudar a los estudiantes a gestionar su carga académica mediante sesiones de estudio pequeñas, planificación organizada y seguimiento del progreso.

## Tecnologías

- Python
- Streamlit
- NVIDIA Nemotron (integración planificada)
- Nebius Token Factory (integración planificada)

## Estado del proyecto

Actualmente, StudyPilot cuenta con una interfaz inicial desarrollada con Streamlit. Las funcionalidades de planificación, seguimiento del progreso e integración con inteligencia artificial están pendientes de implementación.
